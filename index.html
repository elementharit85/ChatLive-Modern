Kredensial Proyek Supabase

Langkah 1: Buat Proyek di Supabase
  1. Buka Supabase.com dan buat proyek baru (contoh: aerochat-app).
  2. Buka Project Settings -> API, lalu salin Project URL dan anon public key ke input di atas.
Langkah 2: Skema SQL (Eksekusi di SQL Editor Supabase) 
-- 1. Buat Tabel Profil Pengguna dengan 4-Digit Friend Code
CREATE TABLE IF NOT EXISTS public.profiles (
  id UUID REFERENCES auth.users ON DELETE CASCADE PRIMARY KEY,
  name TEXT NOT NULL,
  friend_code VARCHAR(4) UNIQUE NOT NULL,
  avatar_url TEXT,
  status TEXT DEFAULT 'online',
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now())
);

-- 2. Buat Tabel Pesan (Teks & Foto)
CREATE TABLE IF NOT EXISTS public.messages (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  sender_code VARCHAR(4) NOT NULL,
  receiver_code VARCHAR(4) NOT NULL,
  content TEXT,
  photo_url TEXT,
  is_read BOOLEAN DEFAULT false,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now())
);

-- 3. Aktifkan Supabase Realtime untuk Pesan Langsung
ALTER PUBLICATION supabase_realtime ADD TABLE public.messages;

-- 4. Buat Storage Bucket untuk Unggah Foto
-- Masuk ke Menu 'Storage' di Supabase, buat bucket baru bernama: 'chat-photos' dengan akses Public.
Langkah 3: Alur Kirim Pesan, Foto & Panggilan Realtime
  • Pengiriman Foto: File foto diunggah ke Supabase Storage (chat-photos) menggunakan supabase.storage.from('chat-photos').upload(...), menghasilkan public URL.
  • Pesan Realtime: Didengar otomatis melalui subscription realtime: supabase.channel('messages').on('postgres_changes', ...) sehingga pesan baru langsung muncul tanpa reload!
  • Panggilan Suara & Video (WebRTC + Supabase Broadcast): Sinyal SDP (Offer, Answer, ICE Candidate, Hangup) dikirimkan melalui Supabase Realtime Broadcast channel: channel.send({ type: 'broadcast', event: 'call-signal', payload: { ... } }). Ini membuat peer-to-peer terhubung langsung secara audio & visual!
